Patches

Split the grid into rectangles. Each rectangle holds exactly one number, and that number is its area.

How to play
  • Drag from one corner to the opposite corner to draw a patch.
  • Tap a patch to remove it. Drawing over patches replaces them.
  • Keyboard: arrow keys move, Enter sets the first corner, Enter again draws, Delete removes, Escape cancels.
  • Valid patches are solid. Patches that break the rules are dashed and striped.
  • One daily puzzle for everyone, plus unlimited practice. Every puzzle has exactly one solution.
